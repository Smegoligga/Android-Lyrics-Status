- Search lyrics shows the length of the song that's playing, and each result shows its own length and how far off it is (e.g. 5:22, −1 s).
- Results can be sorted by best match (synced lyrics with the same title and length first, labelled "Best match") or by closest length.
- Tapping a result opens a small scrollable window with every line of the lyrics and its exact timing, so you can check them before using them.
