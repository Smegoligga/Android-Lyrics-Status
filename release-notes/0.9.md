- New Search lyrics screen (from Now Playing) for when the right lyrics aren't found automatically. Search by song, artist and album.
- Option to leave out tags like feat., prod. or remastered when searching.
- Pick a result to use it for the current song, or use an album's lyrics for your whole album: each song then gets the lyrics of the song with the same name on that album.
- Lyrics you picked, and album choices, can be removed again from the Search lyrics screen.
